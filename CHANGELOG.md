# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] — 2026‑05‑04

### Added

- Async FastAPI project setup with SQLAlchemy 2.0 & Alembic
- JWT authentication, RBAC roles & permissions
- Celery background tasks with Redis
- File upload/download (local & S3)
- WebSocket chat with JWT auth
- Prometheus metrics & Grafana dashboards
- OpenTelemetry distributed tracing
- Rate limiting, caching, structured logging
- Exception handlers & validation error formatting
- Comprehensive test suite (80%+ coverage)
- Docker Compose for dev & production
- CI/CD workflows for testing, linting, type checking, security scanning
- Documentation: quickstart, API, architecture, deployment, contributing
